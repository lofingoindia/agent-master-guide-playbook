# Advanced and Research Frontier

> **Status:** Discovery. Nothing in this section should be treated as a default production pattern without a maturity review and workload-specific evidence.

## Maturity labels

| Label | Evidence expected |
|---|---|
| Production-established | Multiple credible deployments plus repeatable operational guidance |
| Production-conditional | Useful deployments exist, but workload or cost constraints are narrow |
| Emerging | Promising prototypes/papers with limited independent replication |
| Experimental | Early research, preview implementation, or unclear operational behavior |
| Speculative | Useful design hypothesis without sufficient empirical support |

## Research queue

- Reflection, critique/revision, and evaluator-generator systems.
- Learned tool ranking and routing.
- Adaptive prompts and context policies.
- Memory consolidation, experience replay, and procedural memory.
- Agent-generated skills and governed self-extension.
- Reinforcement learning for tool use and long-horizon agents.
- Self-improvement boundaries, evaluation gaming, and rollback.
- Hierarchical agents and world models.
- Computer-use systems and visual action verification.
- Harness evolution and code-as-harness research.
