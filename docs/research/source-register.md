## Refresh cadence

- **30–90 days:** SDKs, frameworks, protocols under active revision, model/provider behavior, preview systems.
- **90–180 days:** production engineering reports, operational platforms, security project guidance.
- **180 days or on contradiction:** foundational papers and stable distributed-systems principles.
- **Immediately:** deprecation, security incident, benchmark leakage, governance transfer, or a documented guarantee change.

Known immediate-watch items at this snapshot: NIST AI RMF revision; OpenTelemetry GenAI agent conventions moving from Development; MCP authorization revisions; and OpenAI's legacy Evals/Agent Builder surfaces scheduled for retirement in late 2026.
